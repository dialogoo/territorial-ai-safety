# Briefs de capítulo

Un brief por página del libro. Es el paso 1 del ciclo de trabajo:

1. **Oscar** escribe, para cada capítulo, el enfoque, los intereses y los argumentos a desarrollar.
2. **Revisamos** la narrativa completa y reorganizamos el libro.
3. **Oscar** reescribe los briefs de los capítulos que cambien.
4. **Claude** redacta los borradores a partir de los briefs.
5. **Oscar** edita y valida capítulo a capítulo.

Cada archivo llega precargado con el contexto que ya se sabe —qué debe establecer la página, qué
no debe afirmar, qué dice el white paper y qué la restringe— para que escribir el brief sea
rellenar un formulario y no enfrentarse a una página en blanco. El contexto precargado es una
propuesta: corrígelo.

## Reglas

- Un brief vacío no bloquea nada: el capítulo se queda sin redactar hasta que lo tenga.
- Ningún borrador inventa hallazgos, cifras ni citas. Lo que no tenga fuente verificada se queda
  como `*TODO: ...*` en el texto.
- Toda fuente se verifica en abierto y se entrega con enlace, publicación y localizador (página,
  tabla o sección) para que puedas comprobarla sin volver a buscarla.
